## Role

You are a senior TypeScript engineer working in this repo's `src/` PWA on the conversation-cards feature.

## Goal

Let a user print a collection through the ordinary system print flow, producing readable card text with no journal excerpts, teaching details, app chrome or metadata.

## Context

- **Parent epic:** #EPIC_07_NUMBER (Prepare for a Conversation: collections and cards)
- **Predecessor issue(s):** #E07_I03_NUMBER (E07-I03: feat(cards): present one card at a time with no tracking). Each must be merged first.
- **SPEC section:** `docs/plans/relationship_communication_agent_prd.md` §3.4 [CC-013]
- **Acceptance criteria advanced:** AC-13
- **Files involved:**
  - `src/ui/screens/prepare/print.tsx`: real print view
  - `src/styles.css`: `@media print` rules
  - `e2e/print.spec.ts`: new, using print media emulation
- **Prior decisions** (full register in `git-issues/2026-11-24_SPEC_summary.md`):
  - Printing is an explicit button that calls `window.print()`. No PDF is generated by the app and nothing is sent to the server (CC-013).
  - The printed output contains the collection name and each card's conversation text, in order. It excludes source excerpts, citations, teaching explanations, AI labels, navigation, device names, account email and timestamps.
  - Cards avoid page breaks inside a card where possible; text is dark on white regardless of theme tokens.
  - A short on-screen note reminds the user that a printed page is no longer protected by the app.
- **State of the world:** The print route is a placeholder.

## Examples

**Test that should pass after this issue lands**
```ts
test("printed output holds card text only (CC-013)", async ({ page }) => {
  await page.emulateMedia({ media: "print" });
  const text = await page.locator("body").innerText();
  expect(text).toContain("When plans change late, I feel unsettled.");
  expect(text).not.toContain("CANARY-TEACHING");
  expect(text).not.toContain("CANARY-EXCERPT");
});
```
